ホスティング
（Hosting）

サーバーや公開環境を借りて
Webサイトやシステムを運用するサービス

ホスティングとは？

ホスティングとは、 サーバーやネットワーク環境を事業者から借りて、 Webサイト・メール・アプリ・データベースなどを インターネット上で公開・運用するサービスです。

自分でサーバー本体、電源、回線、空調、セキュリティを すべて用意するのではなく、 事業者が用意した環境を利用します。

ホスティングの本質は、 「サーバーを自分で全部用意する代わりに、 事業者の環境を借りてサービスを動かす」 ことです。

まずはイメージで理解する

Webサイトを公開するには、 サーバー、回線、電源、空調、監視、セキュリティなどが必要です。 ホスティングでは、 これらの環境を事業者から借りて利用します。


利用者

Webサイトやアプリを公開したい人

ホスティング事業者

サーバー環境や公開環境を提供する会社

インターネット

公開されたサイトやサービスに利用者がアクセス

「自分でサーバー設備を全部持つ」のではなく、 「公開するための土台を借りる」 と考えると分かりやすいです。

何を借りるサービスなのか

ホスティングでは、 単にサーバーだけを借りるのではなく、 サービスを安定して公開するための環境を利用します。

借りるもの 役割
サーバー環境 Webサイト、アプリ、データベースなどを動かす
ネットワーク インターネットからアクセスできるようにする
電源設備 サーバーを継続して稼働させる
空調設備 サーバーの熱を抑えて安定稼働させる
監視環境 障害や異常を検知しやすくする
セキュリティ環境 不正アクセスや物理的な侵入リスクを下げる

Webサイト

ブログ

Webアプリ

データベース

なぜホスティングを使うのか

自宅や自社オフィスでもサーバーを置くことはできます。 しかし、24時間安定して公開し続けるには多くの負担があります。

停電対策

電源障害への備えが必要

回線対策

通信障害や速度低下への
対応が必要

熱対策

サーバーの冷却が必要

保守対応

故障時の調査や交換が必要

ホスティングを使うことで、 サーバー公開に必要な設備管理や運用負担の一部を 事業者に任せることができます。

クラウドとホスティングの関係

クラウドは、 ホスティングとまったく別のものではありません。 広い意味では、 クラウドもホスティングの一種として整理できます。


ホスティング

サーバーや公開環境を借りる大きな概念

クラウド

仮想化されたリソースを柔軟に利用する方式

関係性

クラウドはホスティングの中の一形態

ホスティングという大きな枠組みの中に、 共有レンタルサーバー、VPS、専用サーバー、 クラウドホスティングなどが含まれます。

クラウドホスティングとは？

クラウドホスティングは、 仮想化されたサーバー、ストレージ、ネットワークなどのリソースを 必要に応じて利用する方式です。

物理サーバーを1台借りるというより、 必要な計算資源を柔軟に使う考え方に近いです。

ホスティングとハウジングの違い

ホスティングとよく比較される言葉に、 ハウジングがあります。 大きな違いは、 サーバーを誰が所有するかです。

項目 ホスティング ハウジング
サーバー所有 事業者 利用者
借りるもの サーバーや公開環境 設置場所、電源、空調、回線など
自由度 サービス内容に依存 高い
運用負荷 比較的低い 高い
物理作業 基本的に事業者側 利用者側で必要になる場合がある

ホスティングは「事業者のサーバー環境を借りる」、 ハウジングは「自分の機器をデータセンターに置く」 という違いがあります。

ハウジングを選ぶ理由

ハウジングは手間がかかりますが、 ホスティングより自由に物理構成を組めるため、 特殊な要件がある場合に選ばれることがあります。

Cisco機器、専用Firewall、特殊なストレージ、 GPUサーバーなどを使いたい場合は、 ハウジングが選択肢になることがあります。

ハウジングの注意点

ハウジングは自由度が高い一方で、 運用責任も大きくなります。

ハウジングは、 「自由度」と引き換えに、 物理機器の管理責任や現地対応の負担も持つサービスです。

手軽さを優先するならホスティング、 物理機器や構成の自由度を優先するならハウジング、 という考え方ができます。

GitHub Pagesもホスティングの一種

GitHub Pagesのように、 HTMLやCSSなどのファイルを置くだけで Webサイトを公開できるサービスも、 広い意味ではホスティングの一種です。

利用者はサーバー本体や回線を意識せず、 ファイルをアップロードしてサイトを公開できます。

「自分のファイルを、 事業者の公開環境に置いて見られるようにする」 という点で、 GitHub Pagesもホスティング的な役割を持ちます。

まとめ

ホスティングとは、 サーバーや公開環境を借りて、 Webサイトやシステムを運用する仕組みです。

共有レンタルサーバー、VPS、専用サーバー、 クラウドホスティングなどは、 いずれもホスティングの一種です。

一方でハウジングは、 事業者のサーバーを借りるのではなく、 自分の機器をデータセンターへ持ち込む方式です。

ホスティングは、 「事業者の環境を借りて、サービスを公開・運用する仕組み」 です。 手軽さと運用負担の軽さが大きな特徴です。
